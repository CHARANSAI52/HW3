## Question 1: Convolution from Scratch
A 5x5 image is filtered using a 3x3 kernel with stride 1 and no padding. NumPy array operations and nested loops implement filtering without a built-in convolution function. The expected output is:

```text
[[4 3 4]
 [2 4 3]
 [2 3 4]]
```

Output shape: `(3, 3)`. Changing stride to 2 gives shape `(2, 2)`.
